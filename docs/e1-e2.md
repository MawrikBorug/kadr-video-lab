# Физический протокол E1/E2

Статусы: **NOT_RUN** — не выполнялось; **PASS** — конкретный критерий наблюдён; **FAIL** — критерий не выполнен в указанной среде; **INCONCLUSIVE** — данных недостаточно. Ошибка облачного HTTP-запроса не означает FAIL всей России. Автотесты интерфейса не являются физическим просмотром.

Пустая матрица: [blank-results.json](../protocol/blank-results.json). Все физические строки при сдаче NOT_RUN. Реальные облачные HTTP-пробы находятся отдельно в [probes.json](../evidence/probes.json). Неподтверждённые источники не запускаются до повторной проверки документации.

## Подготовка на iPhone

После независимого аудита и одобренной публикации откройте фактический URL Pages из GitHub. Установите через Safari → «Поделиться» → «На экран “Домой”». Раздельно отметьте Safari и PWA. Запишите версию iOS, браузера, реальную страну/сеть, VPN и фильтры в примечании. Для базовой пробы VPN выключен; не меняйте настройки защиты ради обхода недоступности поставщика.

Не вводите секреты. Убедитесь, что у вас есть право доступа к выбранному контенту. Не загружайте свои копии на GitHub, не снимайте DRM, не меняйте флаги рекламы, не извлекайте скрытые URL. Настоящий iframe и прямой HLS из публичного API — разные режимы, сравнивайте их явно.

Для каждого заявленного типа источника и объекта:

1. Создайте новый сеанс. Укажите E1, реальную сеть и браузер. Откройте источник вручную. Запишите время от команды запуска до первого фактически движущегося кадра со звуком; критерий ≤30 секунд. Таймер внутри стороннего плеера не считается секундомером старта.
2. Отдельно подтвердите: открылась ли страница / JSON; найдено ли точное **полное** произведение (год, версия, длительность), запустилось ли видео. Трейлер, рекламный ролик и заглушка не подходят.
3. Запишите фактический язык, студию озвучки, язык/вид субтитров и качество; рекламное обещание multi-language не подходит. Если этого нет — укажите отсутствие, а не оставляйте предположение.
4. Посмотрите 5 минут. Перейдите к 50% длительности, замерьте возобновление (≤10 секунд), проверьте паузу. Отметьте каждую рекламу отдельно от трекинга.
5. Запишите необходимость оплаты, официального ключа, сервера или другого приложения. Если конечный медиахост виден — только домен, без приватного URL / query. Для cross-origin iframe он часто недоступен; отметьте INCONCLUSIVE в примечании.
6. Экспортируйте JSON. Повторите в домашней и мобильной сетях РФ отдельными сеансами. Нельзя переносить результат одной сети на другую.

AniLiberty заявляет только аниме: другие категории в общей матрице остаются NOT_RUN с пометкой вне заявленного охвата. Не считайте их просмотренными / отсутствующими. Для каждого кандидата считайте отдельно n/3 по четырём категориям и сети; не экстраполируйте 12 объектов на весь каталог. Технический успех по заявленной категории требует хотя бы одного точного объекта на обеих сетях без медиапрокси КАДРа.

## E2 — реклама и управление

Проводится для кандидатов / объектов, прошедших E1. Матрица сред: iPhone Safari / iPhone PWA × домашняя / мобильная сеть РФ; отдельно хотя бы один десктопный браузер. Владельцу не нужен ПК: десктопную строку может выполнить другой проверяющий позднее; до этого она NOT_RUN.

Начните с обычного режима без блокировщика. Затем отдельно повторите со своим стандартным фильтром, записав его название и режим. Для iframe сравните sandbox без окон, sandbox с окнами и документированный режим без sandbox. Последний требует экспорта журнала и подтверждения предупреждения; может открыть окна или сменить страницу. Sandbox не объявляется удалением рекламы и может сломать плеер.

Для короткой пробы: 30 минут, seek в середину и к концу, пауза. Для утверждения **«без рекламы на испытанной выборке»**:

- полный просмотр минимум одного фильма и одного эпизода основного видео;
- повтор обоих в **новой сессии** (полностью закрыть и открыть вкладку / PWA; сохранить различающиеся sessionId и время);
- ноль наблюдённых pre-roll, mid-roll, overlay, pop-up и перехватов навигации во всех перечисленных сеансах;
- среда, фильтры, продолжительность и пределы наблюдения указаны явно. Короткая проба не заменяет полный просмотр.

Трекинг фиксируется отдельно: домен, время и доступный способ наблюдения. На iPhone без сетевого трассировщика cross-origin запросы могут быть недоступны. Тогда трекинг INCONCLUSIVE; отсутствие видимого баннера не означает отсутствие tracking. Не нужен компьютер для ручной фиксации видимой рекламы.

Управление оценивается независимо от рекламы: play / pause / timeupdate / seeked / ended основного видео; пауза командой; реальные дорожки, язык, субтитры; таймер, PiP, смена эпизода; обрыв сети, восстановление и позиция. Для YapGrid документированного внешнего управления нет — отсутствие событий/команд отмечайте как ограничение, не подменяйте их DOM-доступом. У AniLiberty нативный HTMLVideoElement даёт события, но содержание кадра и язык всё равно проверяются человеком.

## Фиксация и передача

Один сеанс — один поставщик, объект, среда и sandbox. Условия после старта заблокированы; для изменения нужен «Новый сеанс». Наблюдения сохраняются автоматически и остаются доступны после закрытия источника. После перезагрузки видео само не запускается. `events` — технические события; `checks`, `ads`, `tracking`, `details`, `status` — ручные результаты. Потеря событий по лимиту отражена в `droppedEvents`.

Перед выходом экспортируйте JSON через «Файлы» / системное меню «Поделиться». Не публикуйте личные примечания в открытом репозитории. Сообщайте только фактически измеренные значения; пустое поле и NOT_RUN допустимы. Итог относится к конкретным сеансам, не утверждает универсальную безрекламность или архитектуру КАДРа.
