# Поиск по кадру и спойлерные разборы

Стенд: https://kadr-video-lab-ai-korotkowwww-4729.vercel.app/ai.html

Это закрытая серверная сборка видеолаборатории под Vercel Authentication. Ключи Groq и TMDB находятся на сервере; пользователь не вводит их в интерфейсе. Основной репозиторий `kadr` этим изменением не перестраивается.

## Пользовательский путь

1. Добавить один–три кадра и, при желании, описание. Изображения показаны в превью: их можно удалить или заменить. Нажать «Найти» и выбрать подходящий вариант среди реальных карточек TMDB.
2. При неоднозначности добавить другой кадр или уточнить описание. После результата, ошибки, отмены или ухода со страницы кадры очищаются; для следующего поиска их нужно выбрать заново. Поиск по известному названию доступен отдельно и не расходует AI.
3. Выбрать карточку и явно подтвердить просмотр фильма либо всех основных серий выбранного сезона. Пункт «Уточнить сюжет по внешним материалам» включён по умолчанию; его можно выключить для ответа только по знаниям модели и метаданным карточки.
4. Получить цельный разбор и прочитать его в интерфейсе. Результат можно скачать. Он обозначен как созданный ИИ, без утверждения о независимой проверке каждого факта.

## Прямой поиск

Исходные кадры и необязательное описание поступают вместе в один запрос мультимодальной модели. Модель сразу предлагает до трёх названий; промежуточного пересказа изображения и последующего поиска другой моделью нет. Если изображений нет, описание получает один текстовый запрос.

Названия сопоставляются с живым поиском TMDB. Неточное предположение о годе не должно автоматически удалять подходящую карточку. Карточка подтверждает существование произведения; совпадение с кадром остаётся гипотезой, которую подтверждает пользователь. Второй обязательный запрос нейросети для разрешения показа кандидатов не используется. Имена файлов, контрольные ответы и лицензионные manifests в запрос модели не входят.

## Прямой разбор

Точная карточка, год и разрешённый фильм или сезон передаются текстовой модели. Один запрос создаёт связную русскую прозу по девяти разделам: краткое резюме; сюжет и финал; смысл; детали и отсылки; создание; персонажи; визуальный язык; теории; источники.

Модель может использовать свои знания. Обязательная добыча цитат, exact-span extraction, подтверждение каждого предложения источником, отдельный модельный проверяющий и автоматический цикл исправлений удалены из рабочего пути. Разделы помогают организовать текст; отсутствие внешнего материала для одного из них не блокирует весь разбор. Интерпретации и версии должны оставаться явно обозначенными; производственные факты, цитаты, авторские намерения и ссылки нельзя выдумывать. Если сведения неуверенные, модель должна сказать об этом.

По умолчанию сервер пытается получить обычный сюжетный контекст выбранного фильма или сезона и передать его модели в том же единственном запросе. Это уточнение входных данных, а не обязательная проверка каждой мысли: пользователь может его отключить, а недоступность материалов не запрещает генерацию по знаниям модели и метаданным карточки. Отображаемые ссылки относятся к действительно полученным материалам, а не к библиографии, придуманной моделью. При отсутствии внешнего контекста раздел «Источники» честно описывает использование знаний модели. Проверка всех интерпретаций по внешним источникам и принудительная замена раздела «Визуальный язык» заглушкой не используются.

Такой порядок выбран по реальным опытам: ответы без контекста серьёзно исказили сюжеты Sintel и Fallout, а обычный сюжетный контекст в том же одном запросе исправил главную историю и развязку Sintel. Это ограниченный результат, не гарантия качества каждого последующего разбора; отдельные фактические ошибки сохраняются.

Подтверждение просмотра и серверные границы спойлеров сохраняются. Подписанное подтверждение привязано к сессии, карточке, сезону и составу основных серий. Выпуск сезона проверяется до генерации; состав и выпуск повторно проверяются перед возвратом результата. Для Fallout S1 действует узкий B04: официальный Amazon сообщает о доступности всех восьми эпизодов и финальном эпизоде, Prime показывает выбранный S1 и серии 1–8, live-состав TMDB совпадает. Для других сезонов без подтверждённого адаптера выпуск остаётся unknown. Само удаление излишних источниковых барьеров не расширяет этот адаптер и не открывает будущие сезоны.

## Изображения и расход

Изображения передаются целиком, без обрезки или растяжения, с учётом EXIF-ориентации. Клиент ограничивает максимальную сторону 1600 пикселями и сохраняет JPEG с quality .94; уменьшает размер дополнительно лишь при превышении 950 КБ. Сервер проверяет формат и размеры. HEIC, который браузер не декодирует, можно заменить снимком экрана или JPEG.

Поиск с изображениями — один вызов модели. Разбор — один вызов модели. Запросы каталога, проверка выпуска и необязательные внешние материалы — отдельные HTTP-запросы, их нельзя выдавать за дополнительные AI-вызовы или за проверку качества текста.

Пиксели и описание находятся в RAM активного foreground-запроса. Нет постоянной очереди изображений, записи загрузок в БД, backup или localStorage/sessionStorage. При скрытии страницы и отмене запрос прекращается, кадры очищаются; автоматического повторного расхода нет. Private Blob хранит только типизированные метаданные допуска, бюджета и отмены. Дневной допуск и интервал между обращениями сохраняются. Провайдерский отказ, превышение входного лимита или недоступность счётчика останавливают запрос без скрытого повтора. Фактические usage показываются отдельно от резервов.

## Практическая приёмка

Для поиска оцениваются попадание правильного произведения в первые три варианта и удобство пользовательского подтверждения на разнообразных реальных кадрах. Воздержание от ответа для некиношного или неразличимого изображения полезно, но не считается положительным распознаванием.

Для разборов оцениваются полезность, соответствие произведению, крупные фактические ошибки, соблюдение границы сезона и содержание согласованных разделов. Машинная схема, число ссылок или успешный HTTP-ответ не являются оценкой качества. Отдельно проверяются серверный доступ, отмена, бюджет и безопасный показ текста.

Автотесты с синтетическими ответами проверяют транспорт, интерфейс и границы доступа; они не доказывают качество модели. Реальные ответы и независимая оценка фиксируются отдельным пакетом. Физический iPhone/Safari остаётся отдельной проверкой. Публикация нового пути сама по себе не закрывает A03/B07 или этап 3.
