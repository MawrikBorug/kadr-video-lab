## Подготовленный безопасный путь

Приватные ключи — только runtime env закрытого backend: `KODIK_API_KEY`, `VOKINO_API_TOKEN`, `VIDEOSEED_API_TOKEN`; Videoseed дополнительно требует `VIDEOSEED_CONTRACT_CONFIRMED=true` после сверки выданного контракта. `KADR_ALLOWED_ORIGIN=https://mawrikborug.github.io` ограничивает браузерный origin, `KADR_ADAPTER_ACCESS_TOKEN` закрывает лабораторный API. Ни одно значение не вставляется в сборку или GitHub Secrets с последующей клиентской подстановкой.

Клиент получает только публичный endpoint и минимальный ответ. Пароль лаборатории может быть введён в отдельное password-поле и остаётся в памяти вкладки; ключи поставщиков в эту форму не принимаются и не нужны. Cookies аккаунтов остаются на сайте оператора. Экспорт и журналы не содержат заголовок авторизации, URL со своими token или произвольный upstream JSON.

Backend-компонент подготовлен в том же репозитории. Создание бесплатного Vercel-проекта отклонено `POST /v11/projects` с 403 на scope текущего подключённого аккаунта. Клиентский endpoint null. Для размещения нужен доступ Vercel с правом создания/деплоя проекта в этом scope; успешное повторное подключение само по себе ещё не доказывает выдачу ключа поставщика. До устранения этой зависимости серверные ключи вводить некуда; размещать их в публичной сборке, GitHub или чате не следует.

Автоматические тесты server → выбранный официальный Kodik iframe используют только фиктивные ключи. Успешные собственные ответы VoKino/Videoseed отсутствуют, их playable-схема не выдумана. Это конкретные остающиеся зависимости, не блокирующие публичный прогон.
