**Решение gate:** имеется минимум один технически интегрируемый анонимный публичный режим — AniLiberty, подтверждённый вплоть до минимального фрагмента доставки. Это разрешает создание стенда, но не утверждение архитектуры или рекламной чистоты. YapGrid подтверждён на уровне контракта; его live доступ отдельно INCONCLUSIVE. Ни один из трёх 403-кандидатов не назван UNAVAILABLE глобально: для этого не хватает данных.

Статус REQUIRES_OWNER_REGISTRATION не назначен никому без доказанного требования. Если после повторного чтения официальной документации понадобится ключ или domain allowlist, кандидат остаётся заблокированным: владелец регистрируется у оператора и получает официальное разрешение. Секретный серверный ключ нельзя вводить в сайт, URL, issue или PR. Источник с таким ключом не проходит условие «статический стенд без бэкенда»; отдельный серверный эксперимент потребует решения владельца.

## Что реально измерено

- AniLiberty: OpenAPI 304 910 байт, описание HLS. Релиз `10301` — «Магия вернувшегося должна быть особенной 2», только контроль транспорта, не подмена 12 объектов E1.
- Проба 04:54 UTC: манифест 16 262 байта, `#EXTM3U`, SHA-256 `57b4b73561116260995d716995f3c9b19427d842bb07afa60207b433ff322948`. Из первого TS прочитано ровно 1024 байта, HTTP 206, Content-Range `bytes 0-1023/1348336`.
- API выдал `countryIso=US`, `isAuthorized=0`, `isWithVideoAds=1`, `isWithVideoAdsAlways=1`. Country-флаг — ответ поставщика, не измерение физической геолокации. Полный видеоряд не скачивался и не просматривался.
- Для Dandadan, Solo Leveling, Frieren получены результаты официального поиска и JSON релизов `9789`, `9600`, `9542`, в них есть ordinal 1 и HLS 480p. Это метаданные, не PASS E1.
- 12 TMDB ID сверены с публичными карточками / поиском TMDB без API-ключа. Существование карточки не доказывает наличие видео у поставщика.

Не установлены: права на внешний показ всего каталога, русский язык / студия в конкретном видео, запуск на iPhone, домашняя / мобильная сеть РФ, полный просмотр, отсутствие вставок или трекинга. Все эти результаты остаются NOT_RUN.
