## Прямая браузерная проба без fixture

[browser-api-probe.json](../evidence/browser-api-probe.json): **INCONCLUSIVE**. Реальная страница стенда в Chromium попыталась получить AniLiberty JSON, но получила `net::ERR_CERT_AUTHORITY_INVALID` при работе через облачный прокси. Сертификат в Chromium не был признан доверенным; проверка TLS не отключалась. Код показал сетевую ошибку, не проставил PASS. Прямой HTTP-клиент с настроенным доверием окружения ранее получил JSON/HLS/фрагмент (probes.json).

Это первая неподтверждённая граница live-браузерной цепочки; дальнейшее декодирование/просмотр не объявляются проверенными. В этой пробе внешние media-запросы заранее запрещены для исключения загрузки видеоряда. Для повторения в облаке необходимо штатно настроенное доверие браузера к CA среды; для реального приёмочного результата нужен физический Safari / PWA в целевых сетях. Нельзя отключать TLS или переносить облачный результат на iPhone.

## Собственная проверка и пределы

Проверены статические endpoints, allowlist медиахостов, отсутствие перезаписи рекламных query, проверка source/origin, закрытие предыдущего плеера и отмена его запроса, ограниченный безопасный лог, восстановление хранилища и экспорт. Данные выводятся через textContent, не HTML. В репозитории нет ключей/токенов, медиакопий и пользовательских результатов.

GitHub Actions закреплены по полученным из официальных репозиториев SHA. PR-workflow имеет только contents:read; Pages пишет только deploy-job из main. Чтение административного Actions permissions API из облачного подключения дало 403 `Resource not accessible by integration`. Это ограничение административного чтения; возможность запуска CI устанавливается по фактическому PR-run.

Фактическая отправка ветки через git также отклонена HTTP 403 (`Permission … denied`). Независимая попытка создать `experiment/kadr-3-3` через GitHub connector вернула 403 `Resource not accessible by integration`. Поэтому право записи не подтверждено реальной операцией, хотя чтение metadata показывало push:true. Удалённая ветка, PR и CI-run не созданы; CI — NOT_RUN. В `main` изменений нет. Требуется исправить права подключения, затем отправить уже готовую ветку и проверить фактический run. Репозиторий заново создавать не нужно.

**Эта собственная проверка не является независимым аудитом.** Отдельное заключение по [review.md](review.md) остаётся NOT_RUN.
