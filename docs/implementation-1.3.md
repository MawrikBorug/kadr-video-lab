## Охват

Все 125 направлений C01–C35, X01–X32, L001–L058 сверены с выполненным исследованием. `web/data/registry.json` сохраняет исходные поля и добавляет текущий `stageReview`; `scope.json` и JSON/CSV сдачи содержат классификацию, способы, отдельные блокеры и ссылки на сделанные проверки. Учитываются самостоятельный источник, агрегатор, оболочка, неизвестный оператор, общий upstream, hosting и инфраструктура. Сходные имена/домены не объявлены одним оператором.

Дополнительные iframe используют точные публичные страницы из зафиксированного Lampac SHA, без исполнения `black_magic`, перехвата потоков, чужих ключей, изменения рекламы, подмены Referer/Origin или DRM. C27 Autoembed.app и L011 player.autoembed.to имеют разные записи; X32 VidFast.to не заменён L012 vidfast.vc. Collaps снова ответил HTML в облачной сети; прежний HTTP 410 сохранён исторически. Его TV iframe адресует произведение, точную S/E выбирает и подтверждает наблюдатель — query не выдуман.

Mikai: анонимный public/v1, точные MAL/год/эпизод, релиз, voice/sub, команды и реальный выбранный upstream. Штатный HTTPS embed берётся только из свежего ответа и проверенного перечня доменов; ссылки не сохраняются в журнале. Ashdi/MoonAnime/Fenix/Tortuga остаются общими зависимостями. Выбранный вариант закрепляется за попыткой; смена upstream/релиза требует новой связанной попытки, чтобы прежние отметки звука и видео не приписывались другому плееру. Каталог MoonAnime с ключом и публичный iframe через Mikai — разные способы.

Зрительские сайты без установленного API имеют отдельный ручной режим внешней вкладки. Он сохраняет ожидаемое произведение и связь с опытом, ждёт результата после возвращения и подтверждения закрытия внешнего плеера. Это не API/media-интеграция и не подтверждение доступности N14. Parent не может принудительно закрыть чужой плеер. Автоматические счётчики вне стенда отсутствуют; возможная выгрузка Safari сохраняет прерванную попытку, а не обещание фоновой работы.

## Телефонные регрессии

`commands.restore.completed` теперь означает подтверждённое восстановление позиции: завершение отмечается по `seeked`/проверке позиции, дальнейший прогресс — отдельным `playbackResumed`. Полное завершение просмотра остаётся в `measurement.completed` и требует конца плюс ≥90% уникальных интервалов. Чат владельца не использован для изменения исторических полей.

Техническая лестница L0–L3 сохранена. Добавлен `evidence` с отдельными `technicalLevel`, `manualMainVideo`, источником и понятной сводкой. Ручное видео в закрытом iframe остаётся полезным подтверждением наблюдателя при техническом L0; play/onload без этого не становятся основным видео. CSV содержит те же различия. L4/L5 не присваиваются автоматически.

Условия для следующих попыток меняются отдельной формой. Каждый новый attempt получает неизменяемые снимки условий и конфигурации, новое время и связь с предыдущим attempt. Условия исходного run и прошлых попыток сохранены. VPN — декларация пользователя с происхождением, не геоизмерение. Прежний unknown не заполнен по чату.

Защищённый iframe остаётся стандартным. Явно подтверждённая диагностика создаёт отдельную связанную попытку без sandbox либо внешнюю вкладку. Диагнозы стенда/sandbox, отказа поставщика, сети, авторизации и конкретного произведения разделены и имеют ручное происхождение. Один sandbox-блокер останавливает только этот режим; возможен явный повтор. Отсутствие конкретного фильма не включает блокировку всего режима.

Для iframe/внешних сайтов профиль пяти минут требует ручного подтверждения основного видео и фактической длительности ≥5 минут; полный профиль — ещё отметки конца. Рекламный полный просмотр допустим для измерения и не становится ad-free. Стеновые таймеры не заменяют наблюдённые минуты. Неизвестный или ошибочный результат можно сохранить как блокер и продолжить.

## Сервер и доступы

Подготовлен ограниченный серверный API с runtime env, отдельной лабораторной авторизацией, фиксированными upstream/операциями, ограничениями запроса/ответа/тайм-аута и белой схемой. Kodik search связан с выбором штатного iframe в клиенте; тест проходит весь путь client → server → фиктивный upstream → выбор iframe. Это синтетическая проверка кода, не выданный доступ. VoKino/Videoseed не получают выдуманный playback parser при отсутствии успешного собственного ответа.

`api/adapter.js`, `vercel.json` и отдельная команда backend-сборки подготовлены для бесплатного Vercel Hobby, без базы и видеопрокси. Создание проекта отклонено API с 403 scope; CLI без активной авторизации, попытка device login остановлена. Backend не развёрнут. Клиентский endpoint остаётся null, ключевые режимы явно заблокированы. Секретов поставщиков исполнитель не получил.

Лимиты адаптера 10 запросов/минуту, 100/день и одна операция действуют на экземпляр процесса. При serverless-масштабировании это не общий гарантированный бюджет аккаунта. Частный лабораторный пароль обязателен; до предоставления безопасного runtime и ключей расход отсутствует.
