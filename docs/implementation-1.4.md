# КАДР 1.4 · очистка и подготовка Videoseed

Основное подключение следующего испытания — Videoseed. Подтверждённых готовых видеоподключений Videoseed сейчас **0**. Кабинет ожидает модерации по сообщению владельца; известный API отклонил оба предоставленных значения ключа базы. Закрытый backend не размещён: Vercel вновь вернул 403 scope. Эти три ограничения учитываются раздельно.

## Что изменено

Основной выбор содержит Videoseed и два разрешённых транспортных контроля Apple HLS / Blender MP4. Для контролей есть отдельный раздел. Основная очередь ограничена Videoseed; каталог без playable URL не считается режимом просмотра. Прежние адаптеры сохранены в коде и доступны только через явно открытый архив диагностики. Старые очереди сохраняются для просмотра/экспорта; их запуск и повтор отключены. Новые очереди имеют `selectionEdition=videoseed-1.4`.

Сохранены ручные ID, произведение, год и S/E, очередь, пауза, отмена, причина пропуска, новые связанные попытки после смены условий, импорт с объединением, полный/частичный JSON/CSV и «Поделиться JSON». Миграция дополнительных полей аддитивная, storage key и schemaVersion=2 сохранены. Автоматического запуска после обновления нет.

Поиск подключён к ограниченному серверному обработчику. Интерфейс отображает полученные сервером произведения и варианты; данные не подменяются N14. Выбор закрепляется за попыткой. Реализован выбор точного названия/года/варианта и заданного S/E, штатный iframe, ручные подтверждения основного видео, русского звука, рекламы и управления. Доступные сезоны показаны из ответа. Новые поля наблюдений — восстановление и доступные команды/события. Автотесты этого контура используют явно синтетическую выдачу, а не доказанный ответ Videoseed.

Для будущего активированного доступа подготовлена отдельная прямая проба по **внутреннему ID Videoseed** из кабинета. KP/TMDB туда не подставляются. Player token вводится в password-поле, остаётся только в памяти вкладки и штатном iframe, не записывается в журнал/сборку. Для сериала точные S/E в этом режиме выбирает и подтверждает наблюдатель в плеере; неподтверждённые query-параметры не добавлены.

## Реальный результат Videoseed

Со скриншотов прочитаны отдельные «Ключ API» и «Ключ API плеера». Шаблон кабинета:

```html
<iframe src="https://tv-1-kinoserial.net/embed/%id%/?token=%token%" width="100%" height="400" frameborder="0"></iframe>
```

Шаблон предусматривает браузерную передачу отдельного player token. Это не разрешение раскрывать ключ базы. Фактические ключи не опубликованы; изображения кабинета с ключами не включены в публичные артефакты.

По известному из исследования `https://api.videoseed.tv/apiv2.php` выполнено четыре запроса собственными значениями ключа базы: без фильтра/по KP и поиск по названию с годом/по KP. Все дали HTTP 200 со `status=error`, `error_info=invalid token`. Это отказ авторизации внутри HTTP 200, не доступный каталог. Значения ключей и URL с token не сохраняются в доказательствах. После сообщения владельца об ожидании модерации запросы прекращены; попыток обхода или заявок оператору нет.

Актуальная документация кабинета недоступна без действующего входа; её ссылка не получена. Маршрут и структура старого API сверены с уже исследованным Lampac SHA `b7ec8e2f1b9bf6fc9a5620d09740eac8f0aed6f3`, модули `Videoseed/Controller.cs` и `Model.cs`. Подготовленный парсер остаётся закрыт `VIDEOSEED_CONTRACT_CONFIRMED`; включение требует актуального контракта и успешного собственного ответа. Неизвестная схема отклоняется, вымышленные каталоги/потоки не создаются.

Публичный корень известного player host вернул 503 в облачной сети. Точный embed произведения не проверен: нет собственного успешного каталога/внутреннего ID. Поиск → точное произведение → озвучки → S/E → плеер → основное видео собственным доступом **не пройден**. Русский звук, реклама, качество, субтитры и управление Videoseed остаются NOT_RUN. Короткое отсутствие рекламы не превращается в вывод об отсутствии рекламы.

Документ различает отсутствие опыта, каталог, диагностику, пропуск и native transport с неизвестной границей основного видео. Он не утверждает, что все 124 направления вообще не имели технических проб. Перспективность не оценивалась. Upstream не наследуют успешность оболочек.

## Размещение и секреты

Ключ базы — только `VIDEOSEED_CONTENT_API_KEY` на сервере, player token — отдельная `VIDEOSEED_PLAYER_TOKEN`. `KADR_ALLOWED_ORIGIN`, `KADR_ADAPTER_ACCESS_TOKEN` и `VIDEOSEED_CONTRACT_CONFIRMED` ограничивают лабораторный контур. Пароли аккаунтов не используются. Backend принимает только фиксированные операции, ограничивает запросы/ответы/тайм-ауты, не проксирует видеопоток. Бюджет 10 запросов/минуту и 100/сутки действует на процесс, не является глобальной серверной квотой.

Vercel GET нужного scope вновь отклонён 403. Проект не создан, домашний сервер/платные ресурсы/обход scope не добавлены. GitHub Pages остаётся действующим стендом. Публичная конфигурация сообщает фактический блокер. Инструкции владельцу передаются в чате.

Торренты, Drive-доставка видео, Lift и новая реализация Kodik не входят в обновление. Предыдущий код Kodik сохраняется только в архиве.

## Проверка и откат

Автоматические тесты проверяют сохранённые архивные пути и текущий интерфейс, ограничение старых очередей, синтетическую цепочку поиска/выбора, S/E, секреты, ручное подтверждение и паузу/повтор. Они не являются физическим испытанием Videoseed на iPhone. Проверки и HTTPS commit прикладываются к сдаче отдельно.

Точка отката — ветка `archive/pre-videoseed-22822d8`, commit `22822d81387728b0d07d31e1e2b5e133d6af813e`. Старая история и артефакты 1.3 сохранены. При откате новая очередь 1.4 также не запускается самостоятельно.
