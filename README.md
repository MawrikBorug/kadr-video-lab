# КАДР Video Lab · Videoseed 1.4

Стенд: https://mawrikborug.github.io/kadr-video-lab/

Основной набор очищен до Videoseed; Apple HLS и Blender MP4 находятся в технических проверках. Архивные адаптеры, история и старые документы сохранены. Старые очереди доступны для экспорта, запуск отключён. Новый стенд не создавался.

**Videoseed пока не готов к просмотру:** владелец сообщил ожидание модерации; известный API отклонил собственные значения ключа базы; Vercel не предоставляет доступ к нужному scope (403). Реальный поиск и видео не подтверждены. Подготовленные поисковый/iframe-пути проверяются синтетическими тестами и остаются отличимыми от фактического доступа.

Описание изменений, контракта и ограничений: [implementation-1.4.md](docs/implementation-1.4.md).

Из приложенного телефонного журнала 1.3 (52 записи, 5 очередей) подготовлены [аудит](evidence/phone-audit-1.4.json) и [124 направления без подтверждённого просмотра](web/data/untested-1.4.json) / [CSV](web/data/untested-1.4.csv). Каталог, native transport без установленной границы основного видео, диагностика и пропуск различаются. Архивирование не означает постоянную неисправность источника. Перспективность не оценивалась.

## Разработка

Node.js 24+, Python 3.

```sh
npm ci --ignore-scripts
npm test
npm run build
node scripts/check-public.mjs
npm run test:browser
npm run package
```

Для системного Chromium: `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:browser`. CI устанавливает браузер Playwright. Старые browser-регрессии явно используют `?archive=1`; основной интерфейс отдельно проверяется в `cleanup.spec.mjs`.

GitHub Actions проверяет и публикует Pages; build-info.json, build.js и service worker позволяют сверить commit. Архив исходников и опубликованной сборки не включает .env, приватные вложения и зависимости. Откат: archive/pre-videoseed-22822d8 (22822d81387728b0d07d31e1e2b5e133d6af813e).

## Серверный контур

server/adapter.mjs, api/adapter.js, vercel.json подготовлены для бесплатного serverless размещения; работающий backend в этой сдаче не заявлен. Runtime env: VIDEOSEED_CONTENT_API_KEY, отдельный VIDEOSEED_PLAYER_TOKEN, KADR_ALLOWED_ORIGIN, KADR_ADAPTER_ACCESS_TOKEN. Активация VIDEOSEED_CONTRACT_CONFIRMED возможна только после сверки актуальной документации кабинета и собственного успешного ответа. Неизвестная схема блокируется. Пароли аккаунтов и видео через backend не передаются.

Секрет базы не помещается в клиент, GitHub Secrets с клиентской подстановкой, журнал или экспорт. Отдельный player token допускается шаблоном кабинета в iframe; в стенде он хранится только в памяти вкладки либо сервере, не в публичном коде. Публичный JSON содержит только состояние доступа и endpoint, когда он действительно размещён.

Торренты, Drive-доставка видео, Lift и развитие Kodik в эту задачу не входят. Исторические документы 1.2/1.3 и исходный реестр 125 C/X/L остаются архивом исследования.
