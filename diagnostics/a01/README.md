# A01 · штатные настройки Lift
Сборка `scripts/build-a01.mjs` добавляет `/a01/` к существующему Pages artifact. Корневые `web/*` не меняются. Относительные manifest id/start_url/scope и SW scope разрешаются в `/a01/`; worker не кэширует медиа, очистка ограничена запросами внутри его BASE. HTTP UUID shim не используется.

На iPhone открыть `/a01/` в Safari, выбрать подключение Lift и Sintel, открыть iframe. После playerReady раскрыть «A01: штатные настройки Lift». Для quality/sound/cc/speed: «Список», «Прочитать», выбрать значение из ответа, «Установить», «Прочитать». Проверить штатное меню и реальный эффект. Нажать «Экспорт JSON A01»: KADR_A01_SETTINGS.json; основной «Экспорт JSON» сохраняет события/позицию отдельно. Оба файла нужны.

Home Screen: добавить именно `/a01/` на экран Домой, открыть значок «КАДР A01», повторить отдельный прогон и экспорт. Физический iPhone не выводится из cloud Chromium. Для прогресса нужны два настоящих viewProgress; реальный ended требует досмотра. Ответ settings не доказывает слышимую дорожку, decoded resolution или уникальное покрытие. Не угадывать pause/seek.
